# Cheatsheets

Guías rápidas de comandos para operar este proyecto. Cada archivo cubre una herramienta o
flujo concreto; están pensadas para copiar/pegar, no para leer de corrido.

| Archivo | Cubre |
|---|---|
| [`docker.md`](docker.md) | Levantar, actualizar, inspeccionar y apagar el stack de `docker compose` |
| [`guardrails.md`](guardrails.md) | Probar el guardrail de PII, inspeccionar la memoria de sesión (checkpointer de Redis), correr evals |

> Todos los comandos asumen que estás parado en `project-agent/` (la carpeta con el
> `docker-compose.yml`).
